Your first installer in three commands

Extract the SDK, keeping runtime/ next to divinepack. These commands build a working demo. Then replace the application files and edit the config.

./divinepack init --dir my-installer
./divinepack validate --config my-installer/installer.json
./divinepack build --config my-installer/installer.json --runtime linux-x64 --output my-output

In PowerShell use .\divinepack.exe and win-x64. On macOS choose osx-arm64 or osx-x64. Native OS graphics dependencies still apply.
